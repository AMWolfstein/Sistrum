# Brand assets

The Sistrum artwork is in `assets/images/` (`logo.png`, `logo-transparent.png`,
`sistrum-horizontal-{light,dark,white}.png`) and in the Android launcher resources.
Preserve the supplied proportions and colors. Do not stretch, rotate, recolor, or add
shadows or gradients to the logo.

`logo/png/mornye-badge@1x.png` and `logo/svg/mornye-badge.svg` are kept only for the
Windows and Linux packaging until those shells are removed (M001-T006).
