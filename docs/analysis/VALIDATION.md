zero failures/errors/skips, including cancellation/resume, checkpoint independence,

error is 2.220446049250313e-16 over 6,144 scalar comparisons.

Non-finite oracle values are matched by class (NaN, positive/negative infinity),
not used as percentage denominators. No files remain outside tolerance.

A focused short-DSD test initially found -70 LUFS versus the oracle's 0: without
100 ms of input, ebur128 emits no metadata. The port now preserves that absence
and the sample-peak fallback. The second full comparison found the floating-point
torture vector's peak becoming permanently NaN; astats actually updates extrema
with comparisons, retaining extrema through NaNs. That source behavior is now
preserved. Two accompanying crest failures were report arithmetic on matching
NaNs, corrected without changing oracle values or tolerances. The next full run
passed all 368 files. An earlier long-vector run was interrupted to replace
per-tap modulo divisions with equivalent power-of-two ring indexing.

## Tempo and onset variance (commit 5)

All 368 oracle files pass. Maximum tempo error is 0.00016736984253 BPM
(on `wavpack-test-suite-2.0/test_suite/legacy/vers-20-lossy.wv.wav`), versus
the 0.5 BPM tolerance. Onset variance matches exactly (maximum relative error
0%, versus 2%). No octave correction or replacement tempo model is applied.
The known 180/190/200 BPM clicks retain the oracle's mean estimates of
100.39035192029229 / 105.9587631225586 / 101.1080420998966 BPM.

The first tempo comparison passed numerically on 365 files; three files hit
aubio's rounded phase-comb access at index 512, just beyond its 512-element
observation vector (click-200, hybrid_corrupt and cue_sheet). The JVM port
zero-pads out-of-window observations instead of reproducing an unsafe native
read. The unmodified native oracle remains the reference; the next comparison
passed all 368 files. The analogous time-signature harmonic accesses are also
bounded by the observation window. Source thresholds, combs, peak picking,
float state, time signature, octave rules and Welford accumulation are retained.
