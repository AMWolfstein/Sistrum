**Input**: spec.md, plan.md (removal inventory), research.md, DECISIONS.md (D-1…D-12)
**Executor**: Codex, autonomous mode (`AGENTS.md`), one fresh session per task via
`.claude/skills/delegate-task/scripts/milestone-run.sh`. Tags `[CLAUDE]` and `[MANUAL]` stop the runner (Claude / owner act, then tick).
App root: `androidApp/src/main/kotlin/com/amwolfstein/sistrum/` (= `app/`), host tests `androidApp/src/test/kotlin/com/amwolfstein/sistrum/`
(= `test/`), device tests `androidApp/src/androidTest/kotlin/com/amwolfstein/sistrum/` (= `androidTest/`).

**Rules for every task**
- Quick gate (`verify.sh --quick`) except the last task of each milestone: full unit suites, `--lint`, `assembleDevQa`, the milestone's device
  classes on the `.qa` build only (`com.amwolfstein.sistrum.dev.qa`; never the daily apps), bisect on failure, logs directory in HANDOFF.
- `[TESTS-FIRST]`: write only the tests; gate with `--expect-fail` when they fail on purpose; the next task makes them pass without
  modifying them. `[HIGH-RISK]`: gpt-6.1-sol high effort. Deleting a test is allowed only when it tests removed native code; list each
  deleted test class and test count in the commit message and HANDOFF (SC-004).
- Strings: remove a key from `values/strings.xml` AND `values-ar/strings.xml` in the same task; `ArabicTranslationCompletenessTest` must pass.
- Never edit `.claude/`, `CLAUDE.md`, `.graphifyignore`, graph files; Claude does it in `[CLAUDE]` tasks.
- Corpus fixtures: `~/.cache/sistrum/oracle-corpus`, `~/.cache/sistrum-waxflow-oracle`, `scripts/test-corpus/README.md`; a test whose
  fixture is absent fails with the rebuild command, never silently skips.
